# Project

ClipShrink is a free, open-source Windows app that shrinks H.264 videos to H.265 or AV1 and checks the quality before you free up any space. This section covers the project side: releases, security, and licensing.

## Report a bug

Open an issue on [GitHub](https://github.com/tophe323/ClipShrink/issues). The [bug report template](https://github.com/tophe323/ClipShrink/blob/main/.github/ISSUE_TEMPLATE/bug_report.yml) asks for the version, your Windows version, graphics card and camera model, what happened, the steps to reproduce it, and where your videos are stored (local disk, Google Drive for desktop, external drive, network drive or other).

## Report a security problem

Do not open a public issue. Use the repository's **Security** tab and **Report a vulnerability**. Details are on the [Security](security.md) page.
